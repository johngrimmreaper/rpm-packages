Reaper RPM Repository Network

This is the directory for independently published RPM channels. Each distribution/release/channel has its own public binary repository and GitHub Pages site, keeping repository growth isolated while preserving the same generated package browser, statistics, storage meter, repository metadata, and installation experience.

Using a channel

Open the channel's repository site and use its generated installation instructions. Each site publishes its own .repo descriptor and public signing-key information, so consumers do not need access to the private build-control repository.

The links above are the target architecture. During migration, a channel link may remain unavailable until its paired repository is created and its first generated snapshot is published.

Reaper RPM repositories · generated channels are independently publishable and independently bounded.
