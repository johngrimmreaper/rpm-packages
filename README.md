# Reaper RPM Repositories

A simple index of the public RPM repositories maintained by Reaper.

## Stable repositories

### [RHEL 9 RPM Repository](https://github.com/johngrimmreaper/rhel9-rpms)
Stable RPM packages for Red Hat Enterprise Linux 9 and compatible systems.

### [RHEL 10 RPM Repository](https://github.com/johngrimmreaper/rhel10-rpms)
Stable RPM packages for Red Hat Enterprise Linux 10 and compatible systems.

### [Fedora 44 RPM Repository](https://github.com/johngrimmreaper/fedora44-rpms)
Stable RPM packages for Fedora Linux 44.

## Testing repositories

> **Testing repositories are not standalone repositories.** Packages published there may depend on packages from the corresponding stable repository above. Enable the stable repository when using its testing repository.

### [RHEL 9 Testing RPM Repository](https://github.com/johngrimmreaper/rhel9-testing-rpms)
Testing and pre-release RPM packages for RHEL 9; may depend on packages from [`rhel9-rpms`](https://github.com/johngrimmreaper/rhel9-rpms).

### [RHEL 10 Testing RPM Repository](https://github.com/johngrimmreaper/rhel10-testing-rpms)
Testing and pre-release RPM packages for RHEL 10; may depend on packages from [`rhel10-rpms`](https://github.com/johngrimmreaper/rhel10-rpms).

### [Fedora 44 Testing RPM Repository](https://github.com/johngrimmreaper/fedora44-testing-rpms)
Testing and pre-release RPM packages for Fedora 44; may depend on packages from [`fedora44-rpms`](https://github.com/johngrimmreaper/fedora44-rpms).
